## Known limits and ambiguities
- M2 hashing: the labelled M2 runs the programs in `--plain time` mode, which hashes nothing (as rust-1 timing does); the user-visible cost of the shipped programs' artifact check is in the unlabelled Rv and Cv lines.
- Tokenizer: the prompt is given as ids (the sv-5 set holds ids), so no tokenizer load is inside any arm; real cis2_ref loads tokenizers (with onig) at start.
- The Python arm is a plain HF forward over the same weights file in fp32, single thread; no generate overhead, no tokenizer. Different arithmetic from CIS-2 (token equality is recorded for information alone).
- Rebuild identity depends on environment details this build controls (remap, SOURCE_DATE_EPOCH, empty CARGO_HOME, build-id none); whether it holds is the measured quantity and was not checked.
- Penguin-built shipped binaries (M1, M2) and the box1 and penguin M4 builds are different builds; summ.py lists the shipped hash next to the M4 hashes as an extra.
