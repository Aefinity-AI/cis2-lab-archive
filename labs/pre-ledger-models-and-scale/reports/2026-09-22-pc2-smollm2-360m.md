## Model
`HuggingFaceTB/SmolLM2-360M` (Apache-2.0), fp32, prompt `"Once upon a time"`,
16 greedy-decoded tokens, spec v0.3b conventions. Same family and tokenizer
as the primary SmolLM2-135M §13.1 vector, but architecturally distinct:
32 layers (vs 9), hidden_size 960 (vs 576), intermediate_size 2560,
15 attention heads / 5 KV heads, `rope_theta=100000` (same as 135M).

Tool used: `src/` Rust reference (`cis2_ref --weights-dir <dir>`), same tool
used for the existing Qwen2.5-0.5B/1.5B "informative" vectors in
`EXPECTED_DIGESTS.md` — **not** `verify3/`, whose C driver hardcodes the
135M weights/config sha256 pins and would FATAL on a different model
(would need a real code change to genericize, out of scope here).
