## MUST
M1. classify.py mis-classifies "ERROR: AddressSanitizer: SEGV on unknown address" as UNCLASSIFIED (kind "asan:SEGV"), not K1. The kind regex `([A-Za-z\- ]+?)(?: on| \(|...)` stops at the first " on", so kind = "SEGV" and `kind.startswith("SEGV on unknown address")` is False. Same for "attempting free on address ..." (kind "attempting free"), and "negative-size-param:" / "memcpy-param-overlap:" (colon: no match, falls to rc=1 UNCLASSIFIED). Reproduced: `python3 -c` with import classify, classify.classify("==1==ERROR: AddressSanitizer: SEGV on unknown address 0x08 (pc 0x55)\n",1,10). The registered K1 names SEGV on an unknown address explicitly, and a NULL deref in C1 (json_array_get/obj_get on missing keys) is the likeliest C1 K1. summ.py recount drops UNCLASSIFIED silently (not in distinct counts, no INVALID, no flag), so C1 K1 would read 0. selftest (123) has no SEGV case. Fix: in classify.py replace the generic ASan regex block by `m = re.search(r'ERROR: AddressSanitizer: ([^\n]*)', t)`, `kind = m.group(1).strip()`, K1 if any(kind.startswith(k) for k in K1_KINDS) (tested in scratch classify_fixed.py: all five cases give K1); add selftest cases for SEGV, attempting free, negative-size-param; add to summ.py: any arm with unclassified>0 prints a loud flag and removes that arm's pair labels until a human classifies it (or a registered-rule decision is written); then rebuild payload (classify.py and selftest.py hashes change, so SHA256SUMS, payload sha, and the pinned wrapper/BUILD hashes change) and re-run tests/run_all.sh.
